# Reproductive targets and modes of action

> **Summary (to expand).** A cross-cutting page mapping *where* each agent acts on
> the reproductive system, so agents can be compared by mechanism rather than brand.

## Targets by level of the reproductive axis
- **Hypothalamus/pituitary (GnRH axis)** — anti-GnRH immunocontraception → suppresses
  LH/FSH. See [Immunocontraception](../agents/immunocontraception.md).
- **Gonad — female (ovary)** — VCD depletes primordial/primary follicles (ovotoxicant).
  See [ContraPest](../agents/contrapest-vcd-triptolide.md).
- **Gonad — male (testis)** — triptolide antispermatogenic effects.
- **Steroidogenesis** — DiazaCon blocks cholesterol synthesis upstream of steroid
  hormones. See [DiazaCon](../agents/diazacon.md).
- **Hormonal cycle / implantation** — steroid combinations (EP-1). See
  [EP-1](../agents/ep1-quinestrol-levonorgestrel.md).
- **Gamete surface (fertilization block)** — anti–zona pellucida (ZP3) antibodies.
